# ぐにゃぐにゃバトル — 物理バトルシミュレーター

Totally Accurate Battle Simulator (TABS) 風の、独自 Verlet 物理エンジン＆ボクセルラグドールで動く3D物理バトルシミュレーターです。  
関節のばね制御でぐにゃぐにゃと歩き、殴り合い、吹き飛び、部位が砕け散るコミカルかつ戦略的な合戦を楽しめます。

## 🕹️ 遊び方・基本操作

### 1. モードを選ぶ
画面上部のモード切替ボタンから、2つのモードをいつでも切り替えられます。

- **🏆 アーケードモード（全10面）**
  - ステージごとに決められた敵布陣に対し、**予算（Gold）上限**と**緑枠の配置エリア**の中で青軍を編成して挑むパズル＆タクティカルモードです。
  - **星評価（★1〜★3）**：ステージクリアで `★1`、規定予算以下でクリアすると `★2`、さらに低予算（倹約ライン）でクリアすると `★3` を獲得できます。
  - **兵種の段階アンロック**：ステージをクリアするごとに新しい兵種が解放され、編成の幅が広がります（進行状況はブラウザに自動保存されます）。
- **⚔️ サンドボックスモード**
  - 予算や配置枠の制限なしで、**青軍（左・手前）**と**赤軍（右・奥）**の両方に全18兵種を自由に配置して実験・観戦できるモードです。
  - 画面上部の「プリセット合戦」から、ワンクリックで様々な名勝負シチュエーションを呼び出すこともできます。

---

### 2. ユニットの配置とバトル開始
1. **陣営選択**（サンドボックスのみ）：左上の「青軍を配置」「赤軍を配置」で配置する陣営を切り替えます（アーケードでは青軍固定）。
2. **兵種選択**：画面下部のユニットバー（または数字キー `1`〜`9`, `0`）から配置したい兵種を選びます。
3. **フィールドへ配置**：
   - **左クリック（ドラッグ可）**：地面にユニットを配置します（ドラッグで連続配置）。
   - **右クリック（ドラッグ可）** または `Shift + 左クリック`：配置済みユニットを消去します（アーケードでは青軍のみ消去可）。
4. **戦闘開始**：画面上部の **「戦闘開始」(Space キー)** を押すとバトルが始まります！
5. **再配置して挑戦**：バトル中や決着後に **「配置に戻る」(R キー)** を押すと、自分の配置を維持したまま編成画面に戻り、すぐに試行錯誤できます。

---

### 3. カメラ・観戦コントロール

| 操作 | 内容 |
| --- | --- |
| **マウス右ドラッグ**（または中ドラッグ） | カメラ回転（オービット視点） |
| **マウスホイール** | ズームイン / ズームアウト |
| **`W` `A` `S` `D` / 矢印キー** | カメラの水平移動（パン） |
| **`Q` / `E` キー** | カメラの高さ（上昇 / 下降） |
| **バトル中にユニットを左クリック** | **ユニット追従カメラ**（その兵士の視点・周囲を追尾） |
| **地面を左クリック / `Esc` キー** | 追従カメラ解除 |
| **`Space` キー** | 戦闘開始 ／ 一時停止・再開 |
| **`R` キー** | リセット（配置フェーズに戻る） |
| **速度ボタン（`0.25x` / `1x` / `2x`）** | スローモーション観戦・倍速進行の切り替え |

## 🗺️ ステージ地形ギミック

アーケードモード後半のステージでは、地形を活かした戦術が勝敗を分けます。

- **🌉 渓谷の一本橋と奈落（第7面）**：中央の細い石橋以外から足を踏み外すと谷底へ落下して即死します。ノックバックの強い突撃や爆風で敵を谷へ突き落とす戦術が有効です。
- **🏛️ 石柱群（第8〜10面）**：フィールドにそびえ立つ石柱は移動を阻むだけでなく、**矢・銃弾・砲弾などの飛び道具を遮蔽**します。射線の確保や遮蔽物を使った接近が重要になります。
- **⚡ 奇襲配置ゾーン（第8面）**：正面だけでなく、敵側面の山道にも味方を配置できる特別エリアが登場します。

## 💻 ローカル環境での開発・実行手順

Node.js 環境があればローカルでもすぐに起動・ビルドできます。

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:5173)
npm run dev

# 物理・戦闘・アーケード全ステージの自動テスト実行 (Vitest)
npx vitest run

# 本番用ビルド (dist/ に出力)
npm run build
```
