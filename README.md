# ぐにゃぐにゃバトル — 物理バトルシミュレーター

Totally Accurate Battle Simulator (TABS) 風の、独自 Verlet 物理エンジン＆ボクセルラグドールで動く3D物理バトルシミュレーターです。  
関節のばね制御でぐにゃぐにゃと歩き、殴り合い、吹き飛び、部位が砕け散るコミカルかつ戦略的な合戦を楽しめます。

## 🕹️ 遊び方・基本操作

### 1. モードを選ぶ
左上の「🎮 ゲームモード・設定」パネル（`☰ モードUI` または `Tab` キーで開閉可能）から、2つのモードをいつでも切り替えられます。

- **🏆 アーケードモード（全10面）**
  - ステージごとに決められた敵（青軍・右側）の布陣に対し、**予算（pt）上限**と**赤枠の配置エリア**の中で自軍（赤軍・左側）を編成して挑むパズル＆タクティカルモードです。
  - **星評価（★1〜★3）**：ステージクリアで `★1`、目標予算（`★2目安`）以下または生存率45%以上で `★2`、さらに低予算（`★3目安`）以下でクリアすると `★3` を獲得できます。
  - **兵種の段階アンロック**：ステージをクリアするごとに新しい兵種が解放され、編成の幅が広がります（進行状況はブラウザに自動保存されます。「🔓 全解放」ボタンでいつでも全兵種を試すことも可能です）。
- **🛠 サンドボックスモード**
  - 予算や解放状況の制限なしで、**赤軍（左半分）**と**青軍（右半分）**の両方に全24兵種を自由に配置して実験・観戦できるモードです。
  - 左パネルの「プリセット編成」から、ワンクリックで6種類の名勝負シチュエーションを呼び出すこともできます。

---

### 2. ユニットの配置とバトル開始
1. **兵種選択**：画面下部の兵種バー（カテゴリタブで絞り込み可、または数字キー `1`〜`9`）から配置したい兵種を選びます。
2. **フィールドへ配置**：
   - **左クリック / タップ**：地面にユニットを配置します（アーケードでは赤枠エリア内、サンドボックスでは左半分＝赤軍・右半分＝青軍）。
   - **右クリック** または **「🗑 削除」モードON時のタップ**：配置済みユニットを1体削除します。
3. **戦闘開始**：画面上部の **「⚔ 戦闘開始」(Space キー)** を押すとバトルが始まります！
4. **再配置して挑戦**：バトル中や決着後に **「↺ 配置に戻る」(Space / R キー)** を押すと、自分の配置を維持したまま編成画面に戻り、すぐに試行錯誤できます。

---

### 3. カメラ・観戦コントロール

| 操作 | 内容 |
| --- | --- |
| **マウス右ドラッグ / 1本指ドラッグ（空白部）** | カメラ回転（オービット視点） |
| **マウスホイール / 2本指ピンチ** | ズームイン / ズームアウト |
| **`W` `A` `S` `D` / 矢印キー** | カメラの水平移動（パン） |
| **`Space` キー** | 戦闘開始 ／ 配置フェーズに戻る |
| **`R` キー** | 配置フェーズに戻る（リトライ） |
| **`Tab` キー** | 左サイドパネル（モード・ステージUI）の表示/非表示 |
| **`H` キー** | 全UI非表示モード（広域観戦）の切り替え |
| **速度ボタン（`⏸ 停止` / `0.25x` / `1x` / `2x`）** | 一時停止・スローモーション観戦・倍速進行の切り替え |

## 🗺️ ステージ地形ギミック

アーケードモード後半のステージでは、地形を活かした戦術が勝敗を分けます。

- **🌉 渓谷の一本橋と奈落（第7面）**：中央の細い石橋以外から足を踏み外すと谷底へ落下して即死します。巨人の大棍棒や爆弾兵の爆風、大鷲の鷲掴みで敵を谷へ突き落とす戦術が有効です。
- **🏛️ 石柱群（第8〜10面）**：フィールドにそびえ立つ石柱は移動を阻むだけでなく、**矢・銃弾・爆弾などの飛び道具を遮蔽**します。射線の確保や遮蔽物を使った接近が重要になります。
- **⚡ 側面奇襲ゾーン（第8面）**：正面本陣だけでなく、敵北側の側面にも味方を配置できる特別エリアが登場し、敵後衛のスナイパーを横から強襲できます。

## 💻 ローカル環境での開発・実行手順

Node.js 環境があればローカルでもすぐに起動・ビルドできます。

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:5173)
npm run dev

# 物理・戦闘・アーケード全ステージの自動テスト実行 (Vitest)
npx vitest run

# 本番用ビルド (dist/ に出力)
npm run build
```
