# エクスブロックスウォー：EXBLOCKS WAR — 物理バトルシミュレーター

Totally Accurate Battle Simulator (TABS) 風の、独自 Verlet 物理エンジン＆ボクセルラグドールで動く3D物理バトルシミュレーターです。  
関節のばね制御でぐにゃぐにゃと歩き、殴り合い、吹き飛び、部位が砕け散るコミカルかつ戦略的な合戦を楽しめます。

## 🕹️ 遊び方・基本操作

### 1. モードを選ぶ
タイトル画面でモードを選びます。プレイ中も左上のパネル（`☰ メニュー` または `Tab` キーで開閉）からいつでも切り替えられます。

- **🏆 アーケードモード（全40面）**
  - ステージごとに決められた敵（青軍・右側）の布陣に対し、**予算（pt）上限**と**赤枠の配置エリア**の中で自軍（赤軍・左側）を編成して挑むパズル＆タクティカルモードです。
  - **第1部（1〜10面）**：基本歩兵から始まり、忍者・巨獣・ドラゴン・三大巨獣の帝国近衛軍団へと立ち向かいます。
  - **第2部（11〜20面）**：暴走バギー・超巨大戦車・巨大ロボット・衛星攻撃兵士などの近代兵器、そしてサキエル・ラミエル・サハクィエル・ゼルエルら神々の使徒が襲来する大激戦！
  - **第3部（21〜30面）**：巨大兵器と新兵種が暴れる特殊形状ステージと、ステージ限定ルール。
  - **第4部（31〜40面）**：灼熱・吹雪・毒沼・重力異常などの状態異常と天候演出が襲う最終決戦。
  - **星評価（★1〜★3）**：ステージクリアで `★1`、目標予算（`★2目安`）以下または生存率45%以上で `★2`、さらに低予算（`★3目安`）以下でクリアすると `★3` を獲得できます。
  - **兵種の段階アンロック**：ステージをクリアするごとに新しい兵種が解放され、編成の幅が広がります（進行状況はブラウザに自動保存されます。「🔓 全解放」ボタンでいつでも全兵種を試すことも可能です）。
- **🔥 チャレンジモード**
  - 自軍2,000pt固定で、ラウンドごとに8%ずつ増えるランダムな敵軍（3,000ptから）に挑むサバイバルです。負け・引き分け・90秒の時間切れで終了します。
  - 使える兵種はアーケードで解放済みのものだけです。前回の編成はラン開始時に自動で呼び出されます。勝つと編成は全員復活して次のラウンドへ引き継がれ、再配置しなくてもそのまま戦闘を開始できます。
  - スコアは基本点・資金差ボーナス・生存ボーナスの合計で、ベスト記録はブラウザに保存されます。
- **👥 友人対戦モード**: タイトルの「友人対戦」から、**ローカル対戦**か**オンライン対戦**を選びます。
  - **ローカル対戦**: 1台で2〜4人が順番に配置するオフライン対戦です。手番が終わると配置は隠され、全員の配置が終わると一斉に戦闘が始まります。
  - **🌐 オンライン対戦**: タワーディフェンスのルールで1対1の対戦をします（詳しくは下のタワーディフェンスモードの「オンライン対戦」）。
    - ホストは部屋名を入れて「作成」で部屋を作ります（パスワードはありません）。作った部屋は「募集中の部屋」の一覧に出ます。
    - ゲストは一覧に並んだ、部屋名が書かれたアイコンを押すとその部屋に入れます。一覧は数秒ごとに自動で更新されます（↻ で今すぐ更新）。
- **🎲 ローグライトモード**
  - ゴールド300G・ライフ3・スターター部隊（兵種を数体ずつ＋陣地レリック1つ）で出撃し、全15ラウンドの突破を目指します。ラウンド5・10はエリート、15は使徒・神のボス（HP2倍）です。
  - ユニットは**勝利後の報酬で手に入れます**。カードは兵種ごとに1枚で、デッキに入れると決まった人数の部隊で出撃します（棍棒兵は8人、剣士は3人、ドラゴンは1体など）。倒れてもカードは失われません。
  - ラウンドの前に 🧭 **作戦室**で出撃の準備をします。ユニット枠（3〜12）とレリック枠（2〜4）の範囲でデッキを組みます。兵種のコストに応じて1枚で1〜4枠使います。配置の操作はなく、近接が前、遠距離が後ろに自動で並びます。カードはボクセルモデルで動いて表示されます。
  - ゴールドの使い道は強化です。ユニット枠（200Gから100Gずつ上昇）、レリック枠（1000G・1500G）、ユニットのレベル（Lv1〜5、HP・攻撃が最大1.8倍）、レリックのレベル（Lv1〜4）を買えます。ゴールドはラウンド開始・勝敗・宝箱で手に入ります。
  - 勝つと3択の報酬を選べます。2枠はユニットカード、残りはレリックかゴールドで、エリート勝利後はユニット枠+1です。持っている兵種のカードは報酬に出ません。すでに持っているレリックが出たら無料でレベルが上がります。負けると勝利の2倍のゴールドと、レアユニットが出やすい報酬の3択を2回受け取れます。
  - 全兵種に「群れ・射撃・爆発・衝撃・炎・雷・毒・分身・機動・巨体」の属性タグがあり、同じタグの兵種を2種・4種そろえるとシナジーが発動します（例: 爆発4種で誘爆、衝撃4種で吹き飛んだ敵が他の敵に当たる質量弾）。
  - 陣地レリックはレリック枠の数まで発動でき、作戦室でON/OFFを切り替えられます。ゲート（増殖・巨大化・縮小・炎・雷・毒）は開戦時に隊列の前から後ろへ通過して、全員を強化します（クリックかSpaceでスキップ可）。強化すると効果が上がります（Lv1〜4。増殖は複製確率25〜100%など）。ゲートの属性はシナジーの数には入りません。トーテム・砲台・召喚ポータルは決まった位置に自動で置かれます。
  - 戦闘中に敵を倒すと、確率で銅・銀・金の宝箱が出現します。戦闘が止まり、1・3・5本のリールが回って報酬（全軍強化・回復・援軍・雷撃の戦闘バフ、ゴールドなどのラン報酬）が当たります。外れが続くほど出やすく、ボスからは必ず金の宝箱が出ます。
  - 負けてもライフが残っていれば次のラウンドへ進めます。ライフは回復せず、通算3敗でランは終了します。ラウンドの切れ目で自動保存され、タブを閉じても続きから再開できます。
- **🏰 タワーディフェンスモード**
  - リアルタイムで進む戦場で、出撃バーのカードをタップして部隊を送り出し、敵の城を壊すモードです。敵を倒すと経験値がたまり、レベルアップで強化を3択から選べます。
  - **🌐 オンライン対戦**: タイトルの「友人対戦」→「オンライン対戦」から遊べます（1人用のスターター選択画面からは入れません）。
    - **1つの戦場で向かい合う対面型**です。部屋を作った人が**ホスト（青・左の城）**、一覧から入った人が**ゲスト（赤・右の城）**になります。ゲストの画面は反対側から見るので、どちらも自分の城が左に見えます。出撃バーや城強化のモデル、城の HP バーも自分の色で表示されます。
    - 戦場は1人用と同じく、円形の城壁と通路のある2倍の長さのマップで、2分ごとに地形が作り直されます（両者で同じ地形）。
    - 両者が自分のカード・お金で兵を出撃させ、相手の城を攻めます。AI の敵ウェーブは出ません。城の HP は両者とも 300 です（序盤から気が抜けません）。
    - **N回目のレベルアップの3択は相手と同じ内容**が出ます（引き直しも同じ回数なら同じ）。何を選ぶかは自由です。**宝箱の出現と中身は各自ランダム**です。宝箱は自動では開かず、1人用と同じく戦場の宝箱を押すと開封の演出が出ます（対戦中なので時間は止まりません）。開けられる宝箱があるときは**城強化の横に宝箱ボタン**が出て、戦場の宝箱を探さなくてもそこから古い順に開けられます。相手の兵を倒すと経験値が1人用の2倍入ります。
    - **スーパーレジェンド**: 最上位のレア度で、**宝箱には出ず、レベルアップの3択でだけ**まれに出ます。
      - 兵種: 幾何神ラミエル・拒絶神ゼルエル・ヤマムロン。出撃コストは **2000G**。**3体のうち1種類しか持てません**（別のものが出たらゴールドに替わります。同じものは強化できます）。
      - 門: 転生の門・輪廻転生の門・増殖ゲート（味方が増える門）。3種のうち持てるのは**1種だけ**（他種の門が出たらゴールドに替わり、同種ならレベルアップ）。対戦では輪廻転生の門の復活は**1体につき2回まで**です。
    - **戦略ボタン**: 「城を狙え！」で全軍が敵兵・魔物を無視して敵の城だけを攻撃、「敵を倒せ！」で従来どおり一番近い敵を攻撃します。全軍（出撃済み・新規とも）に即時適用、切り替えは20秒ロックで、命令は相手の画面にもバナーで知らされます。対戦では城に砲台はありません（城強化は最大HPと自動回復だけ）。
    - **🟡 第三勢力（野生の魔物）**: 戦場のわきの巣に、黄色の魔物が時間とともに湧き続けます。魔物は巣の縄張りに入った兵だけを襲い、城は攻めません。**倒した側に経験値とお金**が入るので、兵を出して狩りに行くほど育ちます。相手が狩場を使い始めたら、こちらも兵を出して横取りを狙いましょう。
      - **野良コボルト**（小型の群れ）: 各陣営の通路の出口の近く。速くてもろく、経験値は小さいが数が多い。序盤の狩場。
      - **苔岩トロル**（大型）: 中央寄りのわきに1分から。硬くて遅いが経験値が大きい。中盤の狙い目。
      - **金角のヌシ**（中ボス級）: 戦場の真ん中のわきに2分30秒から1体だけ。倒した側に最上位の宝箱。倒されると2分後にまた現れます。
      - 兵は近く（12m 以内）の魔物にだけ寄り道します。縄張りに兵がいない間、魔物は傷が治ります。
    - 相手の城を落としたら勝ちです。10分たったら、城の残り HP の割合が多いほうの勝ち（同じなら引き分け）。相手が退室・切断したときも勝ちになります。🏳 で降参できます。
    - 対戦中は一時停止・早送りはできず、強化を選んでいる間も時間は止まりません。操作は約0.3秒後に両方の画面で同時に反映されます。相手の通信が遅れると、追いつくまで戦場が止まります（「相手の通信を待っています」と出ます）。
    - 3分間だれも操作しない部屋は自動で消えます。決着後は同じ部屋で再戦できます。
    - **👁 観戦**: 部屋の一覧には募集中の部屋に加えて**対戦中の部屋（LIVE）**も出ます。押すとその試合を観戦できます（途中から入っても、それまでの試合を早送りして追いつきます）。観戦中は操作できず、✖ で部屋の一覧に戻ります。同じ部屋で次の試合が始まると続けて観戦できます。
    - 部屋探しの画面は、ボクセル調のピクセルアートでルールを7枚のカードにまとめて説明しています。
    - **✨ 演出**: 大事な出来事は立体文字で告知します（ヌシ出現・「討ち取った!!」・城の「第二段階!!」・「残り 60 秒!!」・決着の「勝利!!」など。重なったら重要な順に流れます）。
      - 城が削られると HP バーに削られた量が白く残り、自分の城なら画面の縁が赤く光ります。HP が 30% を切ると心音が鳴ります。城が第二段階に入る瞬間は短いスローで見せ、「近接で攻めよう」と知らせます。
      - 出撃すると戦場に土煙と光の柱が立ち、カードから資金へ「-120G」が飛びます。お金が足りないカードにはたまるまでの円形ゲージが出て、出せるようになった瞬間にカードが光って跳ねます。
      - 続けて敵を倒すと「N 連撃破!」が出て、効果音の音程が上がります（表示だけで報酬は変わりません）。残り 10 秒は 1 秒ごとに数字が出ます。地形変化の 3 秒前からもカウントダウンします。
      - 観戦中は中立の演出（赤い縁なし、「青の勝利!!」など）になり、早送りで追いついている間は演出を最小にします。
- **🛠 サンドボックスモード**
  - 予算や解放状況の制限なしで、**赤軍（左半分）**と**青軍（右半分）**の両方に全35兵種・4種の防衛施設・3種の地形ブロックを自由に配置して実験・観戦できるモードです。
  - 左パネルの「プリセット編成」から、ワンクリックで名勝負シチュエーションを呼び出すこともできます。

- **🔢 ダメージ数値とHPの数字（全モード共通）**
  - 戦闘中、当たった場所からダメージの数字が浮かびます（爆発は赤、炎は橙、雷は黄、毒は緑、衝突は青。大きいほど文字も大きく、300以上は特大表示）。細かい連続ダメージは1つの数字に合算されます。
  - 巨体・ボスは頭上のHPバーにHPの数字も表示します。選択中の兵種も、傷つくと数字が出ます（⚙ 設定の「HP バー」をオフにすると数字も消えます）。
  - 左パネルの「ダメージ数値の表示」で「すべて／大きいものだけ／オフ」を切り替えられます。

### 2. ユニットの配置とバトル開始
1. **兵種選択**：画面下部の兵種バー（カテゴリタブで絞り込み可、または数字キー `1`〜`9`）から配置したい兵種を選びます。
2. **フィールドへ配置**：
   - **左クリック / タップ**：地面にユニットを配置します（アーケードでは赤枠エリア内、サンドボックスでは左半分＝赤軍・右半分＝青軍）。マウスはドラッグで連続配置できます。
   - **右クリック** または **「🗑 削除」モードON時のタップ**：配置済みユニットを1体削除します。
   - **`Ctrl+Z` / 「↶ 戻す」**：直前の配置や全消去を取り消します。
   - アーケードとチャレンジの編成はブラウザに自動保存され、次回そのまま復元されます。
3. **戦闘開始**：画面上部の **「⚔ 戦闘開始」(Space キー)** を押すとバトルが始まります！
4. **再配置して挑戦**：バトル中や決着後に **「↺ 配置に戻る」(Space / R キー)** を押すと、自分の配置を維持したまま編成画面に戻り、すぐに試行錯誤できます。

### 3. カメラ・観戦コントロール

| 操作 | 内容 |
| --- | --- |
| **マウス右ドラッグ / 1本指ドラッグ（空白部）** | カメラ回転（オービット視点） |
| **マウスホイール / 2本指ピンチ** | ズームイン / ズームアウト |
| **`W` `A` `S` `D` / 矢印キー** | カメラの水平移動（パン） |
| **`Space` キー** | 戦闘開始 ／ 配置フェーズに戻る |
| **`R` キー** | 配置フェーズに戻る（リトライ） |
| **戦闘中にユニットをクリック / タップ** | そのユニットをカメラで追跡（何もない場所のクリックや `Esc` で解除） |
| **`P` / `F` キー** | 一時停止 / 早送り（1x → 2x → 4x） |
| **`Tab` キー** | 左サイドパネル（モード・ステージUI）の表示/非表示 |
| **`H` キー** | 全UI非表示モード（広域観戦）の切り替え |
| **`Esc` キー** | カメラ追跡の解除、ユニット選択時の詳細説明オーバーレイを閉じる |
| **`⚙ 設定` ボタン** | BGM・効果音の音量、描画品質、演出の強さ（フル／控えめ／最小）、画面の揺れのオン・オフ、進行データの消去。OS の「視差効果を減らす」が有効なら演出の強さは最小から始まります |
| **`ℹ️ 詳細` ボタン** | 選択中ユニットの詳細説明オーバーレイを表示/非表示 |
| **速度ボタン（`⏸ 停止` / `0.25x` / `1x` / `2x` / `4x`）** | 一時停止・スローモーション観戦・倍速進行の切り替え |

## 🗺️ ステージ地形ギミック

アーケードモード後半のステージでは、地形を活かした戦術が勝敗を分けます。

- **🌉 渓谷の一本橋と奈落（第7面）**：中央の細い石橋以外から足を踏み外すと谷底へ落下して即死します。巨人の大棍棒や爆弾兵の爆風、大鷲の鷲掴みで敵を谷へ突き落とす戦術が有効です。
- **🏛️ 石柱群（第8〜10面）**：フィールドにそびえ立つ石柱は移動を阻むだけでなく、**矢・銃弾・爆弾などの飛び道具を遮蔽**します。射線の確保や遮蔽物を使った接近が重要になります。
- **⚡ 側面奇襲ゾーン（第8面）**：正面本陣だけでなく、敵北側の側面にも味方を配置できる特別エリアが登場し、敵後衛のスナイパーを横から強襲できます。
- **🌵 スラローム砂岩柱とデコイ陽動（第11面）**：千鳥配置された砂岩柱がバギーの突進を防ぎ、敵陣前のデコイがこちらの初撃を狂わせます。
- **🦅 双眸の峡谷と大鷲の急降下（第12面）**：奈落の谷底へ叩き落とそうとする大鷲と、狭路を這い上がる大蛇アナコンダの空陸連携。
- **🏰 敵防衛キャノン砲台＆南北二翼奇襲（第13面）**：敵トーチカのキャノン砲台に対し、北翼・南翼の2方向から挟撃可能。
- **🛰️ 射程40m天頂レーザー＆超前線ステルス急襲（第15面）**：加護トーテムで回復する衛星攻撃兵に対し、敵目前の超前線ゾーンから速攻を仕掛けます。
- **🌀 無限召喚ポータル（第16面）**：敵ロボットの背後から増援を吐き出し続けるポータルを早期撃破する電撃戦。
- **⚔️ 増殖ゲート(x2)と落天爆弾（第19面）**：通過した暴走バギーが2倍に増殖して突入！上空からはサハクィエルの爆弾が降り注ぐ極限の防衛戦。
- **💥 三軍同時展開ゾーン（第20面）**：最強の拒絶神ゼルエルに対し、「北翼包囲軍」「中央決戦本隊」「南翼包囲軍」の3方向から同時進撃する総力戦。

## 💻 ローカル環境での開発・実行手順

Node.js 環境があればローカルでもすぐに起動・ビルドできます。

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:5173)
npm run dev

# 物理・戦闘・アーケード全ステージの自動テスト実行 (Vitest)
npx vitest run

# 本番用ビルド (dist/ に出力)
npm run build
```

### TD オンライン対戦の中継サーバー

オンライン対戦には Cloudflare Workers の中継サーバー（`server/`）が必要です。準備とデプロイの手順は [server/README.md](server/README.md) を参照してください。開発サーバー（`npm run dev`）は `ws://localhost:8787`（`server/` で `npm run dev`）につなぎます。
